عرض متطلبات — تطبيقات وصلة (Wasla)
التاريخ: 2026-08-20

الغرض: إرسال متطلبات لمبرمج/شركة تطوير لتقدير التكلفة والمدة.
المنصة: Flutter (Android + iOS)
الخلفية الحالية: نظام ويب جاهز (Laravel + API)

==================================================
ملخص المشروع
==================================================
1) تطبيق الزبون — للعملاء
   تسوق من متجر وصلة + طلب من مواقع خارجية + دفع ومتابعة الطلبات

2) تطبيق التوصيل — للسائق/المندوب
   استلام الطلبات، تحديث الحالة، تتبع التوصيل

ملاحظة: يُرجى تسعير كل تطبيق منفصل، مع خيار خصم عند تنفيذ الاثنين معاً.

==================================================
التطبيق 1 — تطبيق الزبون (Flutter)
==================================================

1) الهوية واللغة
- واجهة عربية بالكامل (RTL)
- هوية وصلة (لون أساسي تقريباً #1c7282)
- Android + iOS
- إشعارات Push (FCM)

2) الحساب والتسجيل
- تسجيل / دخول / خروج
- الملف الشخصي
- إدارة عناوين التوصيل

3) المتجر المحلي
- تصفح + بحث + فلاتر
- صفحة منتج: صور، ألوان، مقاسات (غير المتوفر معطّل)، سعر ل.س، سلة
- Wishlist اختيارية في المرحلة الأولى

4) الشراء من الخارج (ميزة أساسية)
المنصات: SHEIN / Trendyol / Temu / Noon / Amazon
- لصق رابط منتج → معاينة السعر بالليرة → إضافة للسلة/طلب شراء
- تصفح داخل المنصة من التطبيق (WebView أو API)

5) السلة والدفع
- سلة + Checkout
- طرق الدفع: كاش عند الاستلام، سيرياتيل كاش، MTN كاش، شام كاش، تحويل بنكي، رصيد المتجر
- رفع صورة إيصال عند الحاجة
- صفحة تأكيد الطلب

6) طلباتي
- طلبات المتجر + طلبات الشراء من الخارج
- حالة الطلب والدفع + إشعارات

7) التكامل
- ربط API الحالي (Laravel Sanctum)
- سلة ضيف ثم تسجيل دخول عند الدفع
- الأسعار والرسوم من الـ Backend

8) خارج النطاق
- لوحة أدمن داخل التطبيق (تبقى ويب)
- واتساب / تعديل أسعار الصرف من التطبيق

==================================================
التطبيق 2 — تطبيق التوصيل (Flutter)
==================================================

1) دخول سائق/مندوب + ملف شخصي

2) الطلبات المسندة
- قائمة: جديدة / قيد التوصيل / مكتملة
- تفاصيل الزبون والعنوان والمنتجات والمبلغ وطريقة الدفع
- تحديث الحالة: استلام من المستودع / في الطريق / تم التسليم / تعذّر التسليم

3) خرائط + تحصيل كاش + إشعارات إسناد طلب

ملاحظة: يحتاج غالباً API جديد من الـ Backend.
قبل التسعير: إسناد يدوي أم تلقائي؟ مناطق/عمولات؟ GPS حي؟

==================================================
ما هو موجود حالياً
==================================================
API جاهز تقريباً للزبون: Auth, Products, Categories, Brands, Cart, Orders, Addresses, External preview, Purchase requests, Currency
موجود: لوحة أدمن ويب + Android WebView بسيط
يحتاج غالباً: API تطبيق التوصيل + تحسينات موبايل

==================================================
طلب التسعير من المبرمج
==================================================
1. تكلفة تطبيق الزبون (Android + iOS)
2. تكلفة تطبيق التوصيل (Android + iOS) منفصل
3. تكلفة الاثنين معاً إن وُجد خصم
4. مدة التنفيذ بالأسابيع
5. هل السعر يشمل: تصميم UI/UX؟ ربط API؟ Backend؟ نشر المتاجر؟ صيانة؟
6. تقسيم المراحل (MVP ثم تحسينات)
7. طريقة الدفع (عربون / مراحل)

==================================================
مقترح المراحل
==================================================
A) MVP زبون: تسجيل + متجر + منتج + سلة + دفع + طلباتي + لصق رابط
B) تحسينات زبون: تصفح منصات + Wishlist + Push + UI
C) تطبيق التوصيل: سائق + طلبات + حالة + خرائط
D) اختياري: GPS حي

==================================================
معلومات المشروع
==================================================

النظام: Laravel API + Storefront
اللغة: العربية (RTL)
المنطقة: سوريا (ل.س + محافظ محلية)

اقتراح: ابدئي بتسعير تطبيق الزبون فقط (MVP) ثم تطبيق التوصيل لاحقاً.
