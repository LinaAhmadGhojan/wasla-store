عرض متطلبات — تطبيق الزبون (وصلة)
التاريخ: 2026-08-20

هذا الملف لتطبيق الزبون فقط (منفصل عن تطبيق التوصيل).
المنصة: Flutter (Android + iOS)
الجمهور: العملاء
الخلفية: Laravel API جاهز

==================================================
هدف التطبيق
==================================================
تسوق من متجر وصلة + طلب من مواقع خارجية + دفع + متابعة الطلبات.

==================================================
المتطلبات
==================================================

1) الهوية واللغة
- واجهة عربية (RTL)
- هوية وصلة (#1c7282 تقريباً)
- Android + iOS
- إشعارات Push (FCM)

2) الحساب
- تسجيل / دخول / خروج
- ملف شخصي
- عناوين التوصيل

3) المتجر المحلي
- تصفح + بحث + فلاتر
- صفحة منتج: صور، ألوان، مقاسات (غير المتوفر معطّل)، سعر ل.س، سلة
- Wishlist اختيارية في المرحلة الأولى

4) الشراء من الخارج
المنصات: SHEIN / Trendyol / Temu / Noon / Amazon
- لصق رابط → معاينة سعر بالليرة → سلة / طلب شراء
- تصفح داخل المنصة من التطبيق

5) السلة والدفع
- Checkout
- كاش عند الاستلام / سيرياتيل / MTN / شام كاش / تحويل بنكي / رصيد متجر
- رفع إيصال عند الحاجة
- تأكيد الطلب

6) طلباتي
- طلبات محلية + شراء من الخارج
- حالة الطلب والدفع + إشعارات

7) التكامل
- Laravel Sanctum API
- سلة ضيف ثم دخول عند الدفع
- الأسعار من الـ Backend

==================================================
خارج النطاق
==================================================
- لوحة الأدمن داخل التطبيق
- تطبيق التوصيل (ملف منفصل)
- واتساب / تعديل أسعار الصرف من التطبيق

==================================================
ما هو جاهز في Backend
==================================================
Auth, Products, Categories, Brands, Cart, Orders, Addresses,
External preview, Purchase requests + payment, Currency

قد تحتاج تحسينات موبايل بسيطة (رفع صور، pagination، push) — وضّح إن كانت مشمولة.

==================================================
المراحل
==================================================
MVP: تسجيل + متجر + منتج + سلة + دفع + طلباتي + لصق رابط
مرحلة 2: تصفح منصات + Wishlist + Push + تحسينات UI

==================================================
طلب التسعير (الزبون فقط)
==================================================
1. التكلفة الإجمالية Android + iOS
2. مدة التنفيذ
3. هل يشمل: UI/UX؟ ربط API؟ Backend؟ نشر متاجر؟ صيانة؟
4. تقسيم الدفع
5. تسعير MVP منفصل عن المرحلة 2 إن أمكن
