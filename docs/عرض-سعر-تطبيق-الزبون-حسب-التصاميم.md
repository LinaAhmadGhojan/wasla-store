# عرض سعر — تطبيق الزبون وصلة (حسب التصاميم)

**التاريخ:** 2026-09-07  
**المرجع:** شاشات `application/wasla-ui-*` + `wasla-ui2-*` + `wasla-brands-*` + `wasla-shein-*`  
**المنصة:** Flutter (Android + iOS)  
**الخلفية:** Laravel API جاهز جزئياً  
**العملة المقترحة للتسعير:** دولار أمريكي (أو ما يعادله)

> هذا عرض تقديري للتنفيذ حسب التصاميم الحالية. الأرقام قابلة للتفاوض حسب خبرة الفريق والمنطقة.

---

## ملخص سريع

| الباقة | المحتوى | المدة التقريبية | السعر التقديري |
|--------|---------|-----------------|----------------|
| **A — MVP** | التسجيل + المتجر + المنتج + السلة + الدفع + الطلبات + العناوين + المفضلة (حسب wasla-ui-01…20) | 6–9 أسابيع | **3,500 – 5,500 $** |
| **B — تسوق عالمي** | شاشات Brands + تصفح SHEIN داخل التطبيق + لصق رابط + معاينة سعر | +3–5 أسابيع | **+1,800 – 3,000 $** |
| **C — مميزات وصلة المتقدمة** | بحث بالصورة، محفظة نقاط، إحالة، مقارنة، Style Quiz، سلة ذكية، تتبع، مراجعات… (wasla-ui2) | +5–8 أسابيع | **+2,500 – 4,500 $** |
| **الكل معاً** | A + B + C | 14–20 أسبوع | **7,000 – 11,500 $** |

**تطبيق التوصيل (منفصل):** غير مشمول هنا — يُسعَّر لاحقاً (حوالي **2,000 – 3,500 $** حسب GPS والإسناد).

## 2) ما لا يشمله السعر (ما لم يُذكر صراحة)

- تطبيق التوصيل / السائق
- لوحة الأدمن داخل الموبايل (تبقى ويب)
- رسوم نشر Google Play / App Store
- حسابات المطورين و Apple Developer
- صيانة بعد التسليم (يمكن إضافتها: **150–300 $/شهر**)
- محتوى المنتجات والصور التسويقية
- إعادة تصميم UI من الصفر (التصاميم جاهزة)

## 3) تقسيم الدفع المقترح

| المرحلة | النسبة | عند |
|---------|--------|-----|
| عربون | 30% | بدء العمل |
| منتصف | 40% | تسليم MVP قابل للتجربة |
| تسليم نهائي | 30% | بعد الاختبار والنشر التجريبي |

---

## 4) طلب من المطوّر / الشركة (إن أرسلتِ الملف للغير)

يرجى تأكيد أو تعديل:

1. السعر النهائي لكل باقة (A / B / C) وللمجموع  
2. المدة بالأسابيع  
3. هل يشمل نشر المتاجر؟  
4. هل يشمل أي تطوير Backend إضافي؟  
5. ضمان وصيانة بعد التسليم  
6. عدد جولات تعديلات التصميم المشمولة  

---

## 5) توصية التنفيذ

1. ابدئي بـ **الباقة A (MVP)** حسب wasla-ui-01…20  
2. ثم **B (تسوق عالمي + SHEIN)** — الميزة التجارية الأساسية  
3. ثم اختاري من **C** حسب الأولوية: بحث بالصورة → محفظة/إحالة → مقارنة/Quiz
