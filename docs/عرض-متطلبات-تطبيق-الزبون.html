عرض متطلبات — تطبيق الزبون (وصلة)

نوع الملف: متطلبات لتقدير التكلفة والمدة فقط لهذا التطبيق
المنصة: Flutter (Android + iOS)
الجمهور: العملاء
الخلفية: Laravel API جاهز — التطبيق يتصل بنفس الـ Backend
التاريخ: 2026-08-20

هدف التطبيق

تطبيق موبايل للزبون يتيح التسوق من متجر وصلة، والطلب من مواقع خارجية (مثل SHEIN وغيرها)، والدفع، ومتابعة الطلبات — بنفس منطق الموقع الحالي قدر الإمكان.

المتطلبات الوظيفية

1) الهوية واللغة

  • واجهة عربية بالكامل (RTL)
  • هوية وصلة (لون أساسي تقريباً #1c7282)
  • دعم Android و iOS
  • إشعارات Push (FCM)

2) الحساب

  • تسجيل حساب جديد
  • تسجيل دخول / خروج
  • الملف الشخصي
  • إدارة عناوين التوصيل (إضافة / تعديل / حذف)

3) المتجر المحلي

  • تصفح المنتجات مع بحث وفلاتر (فئة، ماركة، بحث نصي)
  • صفحة منتج: صور متعددة، اختيار لون، كل المقاسات (غير المتوفر معطّل)، السعر بالليرة، إضافة للسلة مع الكمية
  • قائمة أمنيات (Wishlist) — اختيارية في المرحلة الأولى إذا أثّرت على السعر

4) الشراء من الخارج (ميزة أساسية)

المنصات: SHEIN، Trendyol، Temu، Noon، Amazon (وغيرها حسب الإعدادات).

  • لصق رابط منتج → معاينة السعر بالليرة (منتج + شحن + رسوم) → إضافة للسلة / طلب شراء
  • تصفح داخل المنصة من التطبيق (WebView أو كتالوج عبر API)

5) السلة والدفع

  • سلة + Checkout
  • طرق الدفع: كاش عند الاستلام، سيرياتيل كاش، MTN كاش، شام كاش، تحويل بنكي، رصيد المتجر
  • رفع صورة إيصال عند الحاجة
  • صفحة تأكيد الطلب

6) طلباتي

  • طلبات المتجر المحلي + طلبات الشراء من الخارج
  • تفاصيل: منتجات، أسعار، حالة الطلب، حالة الدفع
  • إشعارات عند تغيّر الحالة / تأكيد الدفع

7) التكامل التقني

  • ربط API الحالي (Laravel Sanctum)
  • سلة للضيف ثم تسجيل دخول عند الدفع
  • رفع صور الإيصالات
  • الأسعار والرسوم من الـ Backend

خارج النطاق

  • لوحة الأدمن داخل التطبيق (تبقى ويب)
  • تطبيق التوصيل (ملف متطلبات منفصل)
  • إرسال واتساب من التطبيق
  • تعديل أسعار الصرف من التطبيق

ما هو جاهز في الـ Backend

  • Auth / Products / Categories / Brands
  • Cart / Orders / Addresses
  • External platforms + preview رابط منتج
  • Purchase requests + submit payment
  • Currency
قد تحتاج تحسينات بسيطة للموبايل (رفع صور، pagination، push tokens) — يرجى توضيح إن كانت مشمولة بالسعر.

مقترح المراحل

  • MVP: تسجيل + متجر + منتج + سلة + دفع + طلباتي + لصق رابط خارجي
  • مرحلة 2: تصفح المنصات داخل التطبيق + Wishlist + Push + تحسينات UI

طلب التسعير (تطبيق الزبون فقط)

  1. التكلفة الإجمالية (Android + iOS)
  2. مدة التنفيذ بالأسابيع
  3. هل السعر يشمل: تصميم UI/UX؟ ربط الـ API؟ أي Backend إضافي؟ النشر على المتاجر؟ صيانة بعد التسليم؟
  4. تقسيم الدفع (عربون / مراحل)
  5. تسعير MVP منفصل عن المرحلة الثانية إن أمكن
