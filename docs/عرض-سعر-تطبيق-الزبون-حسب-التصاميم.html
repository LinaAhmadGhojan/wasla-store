عرض سعر — تطبيق الزبون وصلة (Wasla)

حسب التصاميم: wasla-ui / wasla-ui2 / wasla-brands / wasla-shein
المنصة: Flutter (Android + iOS) — Backend Laravel جاهز جزئياً
التاريخ: 2026-09-07
أرقام تقديرية للتنفيذ حسب الشاشات الجاهزة. قابلة للتفاوض حسب خبرة الفريق والمنطقة.

ملخص الباقات

الباقةالمحتوىالمدةالسعر التقديري
A — MVP 20 شاشة أساسية (تسجيل، متجر، سلة، دفع، طلبات، ملف…) 6–9 أسابيع 3,500 – 5,500 $
B — تسوق عالمي Brands + SHEIN داخل التطبيق + لصق رابط + سلة مختلطة +3–5 أسابيع +1,800 – 3,000 $
C — مميزات متقدمة بحث بالصورة، محفظة، إحالة، مقارنة، Quiz، سلة ذكية، تتبع… +5–8 أسابيع +2,500 – 4,500 $
الكل معاً A + B + C 14–20 أسبوع 7,000 – 11,500 $

تطبيق التوصيل: غير مشمول — تقديراً لاحقاً 2,000 – 3,500 $.

الباقة A — الشاشات الأساسية

  • Splash + Onboarding + Login + Signup
  • Home / Categories / Search / Product
  • Cart / Checkout / Order success
  • Orders + Order detail / Favorites
  • Profile / Addresses / Notifications / Support / Settings
  • عربي RTL + هوية Teal + ربط API + دفع محلي + رفع إيصالات

الباقة B — تسوق عالمي

  • wasla-brands-01…04: متاجر عالمية، رئيسية، SHEIN، سلة
  • wasla-shein-01…04: لكِ، جديد، فلاش، تصنيفات
  • لصق رابط → معاينة بالليرة → طلب شراء

الباقة C — مميزات ui2

  • بحث بالصورة (ربط Image Search)
  • محفظة نقاط + إحالة أصدقاء
  • مقارنة منتجات + Style Quiz
  • سلة ذكية باقتراحات + تتبع + مراجعات + فلاش

خارج النطاق

  • تطبيق السائق / التوصيل
  • لوحة أدمن داخل الموبايل
  • رسوم نشر المتاجر + حسابات المطورين
  • صيانة بعد التسليم (اختياري: 150–300 $/شهر)
