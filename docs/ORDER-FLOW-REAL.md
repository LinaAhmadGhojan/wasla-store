# فلو الطلبات الحقيقي — وصلة (مثل SHEIN / Temu)

**تاريخ:** 2026-09-07  
**القاعدة:** الزبون يشوف **طلبية واحدة**. داخلها أصناف؛ كل صنف له **مصدر** = وصلة / SHEIN / Temu…  
ما في «طلب شراء منفصل» للزبون. الشراء الخارجي يبقى مربوط داخلياً بنفس رقم الطلبية للأدمن.

---

## حالات الزبون فقط (واجهة + واتساب + تتبع)

```
بانتظار التأكيد  →  قيد التجهيز  →  تم الشحن  →  خرج للتسليم  →  مستلم
(+ توقيع / إثبات الاستلام عند التسليم)
```

| حالة داخلية | نص الزبون |
|------------|-----------|
| `pending` | بانتظار التأكيد |
| `preparing` (و `confirmed` قديم) | قيد التجهيز |
| `shipped` | تم الشحن |
| `out_for_delivery` | خرج للتسليم |
| `delivered` | مستلم |

**مو حالات للزبون** (لوجستي داخلي فقط):

- إسناد سائق / مندوب
- وصل للسنتر
- مستودع محلي / استلام تغليف
- الشحن قدموس داخل سوريا
- الشحن بالخارج

الأدمن يسجّلها كملاحظات لوجستية — ما تغيّر شريط حالات الزبون.

---

## تأكيد الطلب = بدء التجهيز

| طريقة الدفع | عند الطلب | بعد تأكيد الأدمن للدفع |
|------------|-----------|------------------------|
| كاش عند الاستلام (COD) | مباشرة **قيد التجهيز** + رقم تتبع | — |
| تحويل / بطاقة / … | **بانتظار التأكيد** | **قيد التجهيز** |

مثل SHEIN/Temu: الزبون ما يشوف «تم إسناد سائق» كمرحلة رئيسية.

---

## كيف تتشكّل الطلبية عند Checkout

```
سلة فيها:
  - فستان وصلة
  - حذاء SHEIN
  - عطر Temu

→ Order واحد (#123)
   ├─ OrderItem: فستان | مصدر: وصلة
   ├─ OrderItem: حذاء | مصدر: SHEIN  ──► PurchaseRequest مرتبط order_id=123
   └─ OrderItem: عطر  | مصدر: Temu   ──► PurchaseRequest مرتبط order_id=123
```

---

## فلو الزبون (ملخّص)

```
1) Checkout
   COD  → preparing + واتساب «تم تأكيد طلبك… بدأنا التحضير»
   دفع  → pending  + واتساب «استلمنا طلبك… منؤكّد الدفع»

2) الأدمن يؤكد الدفع (إن لزم) → preparing

3) الأدمن: تم الشحن → shipped (+ OTP يظهر للزبون)

4) الأدمن/السائق: خرج للتسليم → out_for_delivery
   (إسناد المندوب ممكن قبل/مع هالخطوة — داخلي)

5أ) تسليم: OTP + توقيع/صورة → delivered = مستلم
5ب) فشل → failed_delivery (ثم إعادة خرج للتسليم أو مرتجع)
```

---

## الأدمن

- **حالة الزبون:** القائمة أعلاه فقط.
- **لوجستي داخلي:** نموذج منفصل (مستودع / تغليف / سنتر / قدموس / خارجي).
- **إسناد سائق:** ما يغيّر حالة الزبون؛ يولّد OTP/تتبع عند الحاجة.
- تايملاين الأدمن يرى كل شيء؛ صفحة `/orders/{id}/track` ترى أحداث الزبون فقط.

---

## واتساب

يُرسل فقط عند مراحل الزبون (تأكيد/تجهيز/شحن/خرج للتسليم/مستلم/فشل/إلغاء) — **بدون** رسالة «تم إسناد سائق».
